BookProject
A layered .NET solution built with a clean, modular architecture.

Structure
Dom — Domain models and core logic

App — Application layer

Infra — Infrastructure (data, external services)

Shared — Shared kernel

Api / BookProjectApi — REST API layer

Translator.MServ.Api — Translation microservice

Tst — Unit tests

Tech
.NET, ASP.NET Core Web API, Microservices, EF Core

Getting Started
Clone the repo

Restore dependencies: dotnet restore

Run the API: dotnet run --project Api
